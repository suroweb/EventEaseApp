# EventEase Development Skills

This directory contains specialized skills that extend Claude's capabilities for EventEase development.

## Available Skills

### code-generator
Generates boilerplate code for common patterns (controllers, services, entities, DTOs).

### api-documenter
Generates comprehensive API documentation including OpenAPI/Swagger specs.

### test-generator
Creates unit and integration tests for existing code.

### migration-creator
Creates Entity Framework Core migrations with proper indexing and constraints.

### performance-analyzer
Analyzes code for performance issues and suggests optimizations.

## Usage

Skills can be invoked through the Claude Code interface and provide specialized, focused capabilities for specific development tasks.
