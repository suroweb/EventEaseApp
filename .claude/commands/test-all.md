# Run All Tests

Run all unit and integration tests with coverage reporting.

## Usage

```
/test-all
```

## What This Command Does

1. Runs all unit tests in `EventEase.Tests.Unit`
2. Runs all integration tests in `EventEase.Tests.Integration`
3. Generates code coverage report
4. Displays summary of results
5. Highlights any failing tests

## Coverage Requirements

- Controllers: 90%+
- Services: 95%+
- Domain Logic: 100%
- Overall: 85%+
